# ti84-formula-practice

`ti84-formula-practice` is a lightweight Go CLI for generating short algebra and graphing-calculator practice prompts. It is useful for teachers, tutors, and students who want quick warm-up questions before working through calculator-based examples.

## Installation

```bash
go install github.com/Content-true/ti84-formula-practice@latest
```

## Usage

```bash
ti84-formula-practice --topic slope
ti84-formula-practice --topic quadratic
```

## Calculator Practice

When a problem needs graphing, table inspection, or quick function checks, [TI 84 Calculator Online](https://ti84.io/) provides a browser-based TI-84 style calculator that can support the same kind of classroom practice.
